## 2. 存储总账（审计逐项复算通过）

**TMEM（512 恰满，冻结项 R12）**：dQᵀ r0/r1 各 128（M256 无折叠，跨 16 bundle 持久，L8）
+ S 乒乓 32+32 + dP 乒乓 32+32（M128 折叠 [own-kv64×h64]→32 col/chunk）+ dV 槽 64 + dK 槽 64。

**SMEM（231,424 / 232,448，余 1,024；全项 Align-1024 → struct 恒等 = CG2 同地址规则构造性满足）**：
mbar 块 1,024（清单 ≈33 枚，上界断言 ≤512B）｜stats 1,024｜Q 面板 65,536｜dO 面板 65,536｜
K chase 2×8,192｜P slab 16,384｜dS slab 16,384｜供应环 2×16,384（tile 末别名 dq_epi 暂存 32,768，
相位 mbar 把关）｜**dq_b 双 chunk 像 2×8,192（修复件）**。

**dq_b 双像规格（L2/L3 违例修复的落地形态）**：每 chunk 相位像 = [kv128 × own-N-half 32头]，
两个连续 4,096B 子块（子块 j = kv[64j,64j+64)×own-32头），与 P/dS slab 的 MN_SW128 逐字节同构。
填充三步：dS slab stmatrix 落地（G4 用）→ own 半 h-half==rank 的 2 warp 二次落地 4,096B
（+16 STSM/bundle ≈ +0.05-0.1）→ peer 半 1 条 4,096B bulk DSM（fence 后）。DSM 字节纠账：
8,192B/CTA/bundle 单记，与 own 像 8,192B 相抵，字节近中性。

**三像 stmatrix 门（R3，rev0 零 GPU）**：T2R 强制 Ld16x256bOp(Rep4)（16dp×256bit）→
get_smem_store_op 命中 f32→bf16 x4 子句（源码 :296 逐字核实，不查 majorness）→
StMatrix8x8x16bOp x4 .trans。三像逐像 build-time assert（isinstance ∧ x4 ∧ 双像三联 ∧
子块堆叠 2,048 el ∧ owns-half warp-uniform）；SASS 门：80 STSM/bundle ∧ 零 STS.U16/PRMT（v8 前科）。

## 5. period 模型（修正版：统一 per-bundle 口径 + 两界呈现）

**池需求（warp·µs / bundle / CTA，锚点注明）**：

| 项 | 乐观界（探针锚） | 保守界（v12 实核锚） |
|---|---|---|
| exp+dS 链（8,192 融合元/bundle） | 8.5-9.5（探针 8w 档 1.06-1.19µs） | 17-19（若实核 2× 探针开销延续） |
| T2R | 4.8（v17a 0.6µs/tile ×2 ×4w） | 同 |
| 三像发布 | 11-13.6（v17a MATH_STORE 率 ×1.25 字节比） | 同 |
| stats 广播 | 0.2-1.2 | 同 |
| drain（T2R 波切 + 512 REDG + fence） | 27-33（REDG 有效 31.6-43ns/instr，v11 实核锚 + D1 工程） | 38-50（v12 reduce 轨道率 ×2 字节，工程未兑现） |
| **池合计** | **51-62** | **75-88** |

```
池墙(per-64kv) = 合计 / 12 warp / 2(bundle=2周期) = 乐观 2.1-2.6 ｜ 保守 3.1-3.7
period = max(池, 供应 2.3-2.9, MMA 1.69+泡≤0.4) + 接缝 0.3-0.5
       = 乐观 2.9-3.4 ｜ 中枢 ~4.0-4.5 ｜ 保守 4.2-5.0
```

**两界间的摆锤 = warp·µs 可加性**（混合驻留干扰，批评家第 5 项，全模型第一假设）——rev1 新增
关键探针（§8）。发布口径：**验收 ≤4.8 高置信；平价 ≤4.71 需可加性 + drain 工程两项兑现；
乐观界若成立则显著穿越平价**。灵敏度 ∂period/∂池 = 1/24 per warp·µs（bundle 口径）。
D 分件原报"4.2-4.9 中心 4.5-4.6"经修正后为**中枢偏保守的读数，保留为发布口径**。
REDG 验收门修正（审计 major）：**有效 ≤60ns/warp-instr**（v11 实核已达 ~32-43，余量 ≥1.4×），
弃"≤150ns 串行口径"（该门可放过超预算 2.5× 的 kernel）。

## 6. 规格收敛裁决（三份图纸矛盾的总设计师终裁）

1. **dqb_ready[c]**（三份规格冲突，主案生死门 R1）：终裁 = 每 CTA 本地 cluster-mbar 一枚/chunk 相位；
   **expect_tx = 4,096B（唯一入境 peer push）∧ own-arrive count = 4**（发布 squad 每 warp elected
   lane）。物理依据：每 CTA 每 chunk 只有一条 4,096B push 入境；C 图的"8,192 双 push 聚合"记账
   作废。rev0 对账断言按此写。
2. **dkv_free count = 8**（C-6 维持）：CG2 单点发射下下一 round 需双 CTA 槽均空 → 簇级门，
   本地 4 T2R-warp arrive + mapa 对端 4。
3. **chase_full/ring_full 升簇级**（死锁审计 major-1 采纳）：leader 发射 UMMA 前须确证 peer 片
   驻留 → gather/W1 落地 arrive 本地 + mapa 对端（与 CG 族同机器）；mbar 预算不变（±计数）。
4. **DSM push 移交发布 squad**（批评家第 2 项采纳）：X(c) 由 dS 发布 squad 的 elected lane 在
   fence 后顺手发射，W1 纯供应化——W1 序死锁隐患（N-1 反例）连根消失，R10/V-6 断言改为
   "X 仅由发布者在 fence 后发射"不变量；math 迟到不再同时打穿两墙（R6 耦合降级）。
5. **leader 预算闭账**（批评家第 4 项）：224 原子 × 8-16ns + 8 门等待 ≈ 2.2-4.0µs/bundle，
   rev0 静态清点 + rev2 IKET leader-busy 签名 ≤4.0（新增 R13）；历史 73ns/atom@48regs 病理
   由全员 128 免疫。
6. **per-squad 甘特/backlog**（批评家第 3 项）：3-bundle 轮转的稳态排空条件余量仅 0.1-0.7µs
   （B 自表单 bundle 峰值 5.9-6.6 warp·µs>period），rev0 新增**宿主仿真义务**（mod-5 环仿真
   先例）：静态轮转表 + 修正 warp·µs 账跑 48 bundle，max backlog 有界 + squad 空闲率输出；
   超限 → 轮转周期 3→4 重裁（结构零变更）。

协议 → dq_b 双像 → epilogue/接缝 → 注销清单七项（删码 SASS 复核零残留）。验收签名：
exp 聚合 ≤1.19/8192 融合元｜发布 80 STSM 零 STS.U16｜REDG ≤60ns/instr 有效｜ring_full =
6 圈×0.38-0.46｜CG_P[c0] ≤0.4、CG_P[c1] ≤0.6、DV(3) 尾 ≤0.4｜leader busy ≤4.0/bundle｜

## 9. 墓碑增补

1. **cp.reduce.async.bulk 二次处决（V4 几何下重审后维持）**：262,144B/bundle ÷ 512B/条 =
   512 条 × 50ns 引擎时间 = 25.6µs/CTA/bundle，vs 池化 REDG 折算 elapsed ~2-3µs——劣 ~10×，
   且 SMEM staging 无余量（1,024B）。与 CONFIG B 原判（环上税）死因不同（引擎吞吐税），双重死。
2. **M5-B（4 warp 160-176 regs fragment 流水）判死**：池预算无解（61,440+WG0 超帽）+ 探针证
   "ILP 弱于加 warp"；弃池化形态整族不复活。
3. 分件间单位混账（per-bundle vs per-64kv）列为流程判例：**一切 warp·µs 账必须标注
   /bundle 或 /64kv 并给换算行**——本次 fatal 的直接制度化。
