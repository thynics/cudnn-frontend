# rubin_2 设计规格：dO 全量面板 + dV-A 零拷贝（Rubin-only，2026-08-10）

**战役**：超越 baseline（GR100 3.12µs/tile；当前最好 ck 4.145）。
**平台约束（goal 增补）**：不考虑任何 B200 兼容性——单一 Rubin profile，
无 COMPAT/E3PAD 臂，K1a 寄存器布局（64/64/128/120）为默认且唯一。

## 1. 核心思想：用 Rubin 独占的 +100KB SMEM 买断 dO 的全部供应机器

B200 判死的"全量面板"（Q+dO 双复制需 330-355KB）在 328KB 悬崖下不稳；
**单复制 dO** 是被漏掉的中间态：

- `stationary_do`：64KB（h-half）→ **128KB（全 H128）**，两 CTA 持相同字节、
  相同地址 → **CG2 共享描述符 rank 同址锁自动解开**；
- dV 四个 pass 的 A 操作数（dOᵀ [D128×H64] 象限）从"每 tile 经环重演"变为
  **stationary 的 recast 零拷贝视图（永生，baseline 同款）**——S1 布局恒等
  已硅上验证，当年仅死于同址锁+容量，本设计双锁齐解；
- 供应环 10 代/tile → **6 代**（2 kdq + 4 Q 象限）：W17 发射量 −40%，
  W19 提交等待 −50%，dO 侧 TMA/bulk 全部蒸发。

## 2. 字节账（单一 Rubin profile，cap 334,848B）

```
mbar 区（rubin_1 单面口径）        ~1,024
stationary_q                      65,536
stationary_do（全量）            131,072
score_kv                          32,768
round 环 3×16,384（6%3=0 相位合法） 49,152
P/dS 单面（blocks8+xchg4+image8+blocks8）28,672
stats                                512
──────────────────────────────────────
≈ 308,736B ≤ 334,848 ✓（余 ~26KB）
```
环深选 3（6 代 %3=0 ✓）：比 rubin_1 的环 5 省 32KB，同时 Q 侧供应前瞻
2 代（K1a 后供应节拍 ~0.1-0.15µs/gen，2 代前瞻 ≈0.3µs > 圈时）。
若实测供应又成 pacer，环 6（+48KB≈357KB ✗ 超）不可行，环 3 是终点。

## 3. 预算表（k4-r1/r2 悬崖税重定价腿供数）

- 收益侧（B200 系数保守折算）：dO 4 代供应链（TMA/bulk 发射+信用+提交）
  蒸发 + dV-A 永生 ≈ −0.3~0.6µs/tile；代码形状简化（无 loan/无双面/无
  dO 环臂）→ spill 面收缩，nk 实测结构溢出 ×1.15 有望归零；
- 成本侧：悬崖费（k4 实测值，预期 +0.15~0.35）+ dO GMEM 读 ×2/token
  （~128KB/cluster，L2 热，摊到 32 tile ≈噪声）；
- **判决预期：net −0.1~−0.4µs/tile vs ck**。若 k4 判 cliff_cheap（≤0.15），
  预期上修。

## 4. 实现要点（新文件 dsa_bwd_sm100_2cta_rubin_2.py，Rubin-only）

1. 基座 = rubin_1 的 native 臂代码路径（环 N/单面），删除全部
   COMPAT/E3PAD/SPIN_K2 分支与双面臂；K1a 寄存器为常量。
2. `stationary_do` 全量：stationary TMA 的 dO 腿从 rank 半区改全 H128
   （两 CTA 各自加载全量；`t_do_gmem` 分区去掉 rank 索引）；
   dP 的 A 片段照常取本 rank 半区视图（字节超集，布局不变）。
3. dV pass A 操作数：`loan_quad/round_quad(dO)` 片段替换为
   `stationary_do` 的 recast 零拷贝视图（baseline `_load_grad_k`/`:841`
   同款 MN-major 象限 recast；host assert 字节恒等）。
4. 环代重排：6 代 = kdq0,kdq1,Q_r0h0,Q_r0h1,Q_r1h0,Q_r1h1；
   PANEL_SLOTS mod-3 字面量表；W17/W19 循环收缩；dkv head/tail 的
   loan_quad 等待与 relay 门保持（P/dS 交换机器不动）。
5. 每 tile MMA 序不变（S、dP、2×dQ、8×dVdK）；dV pass 直接消费
   stationary 视图片段——无 kscore 借宿、无环等待。
6. 验收：4-case correctness 硬门 + k5 配对腿（rubin_2 vs ck vs nk），
   预登记带：≤−0.05 有效 / ±0.05 中性 / >+0.05 回退（回退必析因）。

## 5. 风险与对抗（防复议预登记）

- **视图合法性**：唯一硬风险。S1 恒等 + 同址双解的推理若被工具链拒绝
  （descriptor 校验/布局断言），退路 = dO 侧保留 2 代环但源改为本地
  stationary 全量 bulk（仍省 GMEM TMA 与跨 CTA 依赖，收益打七折）；
- 悬崖费若 k4 判 anomalous（>0.45）：本设计冻结，回到 math 墙（M2）；
- dP 的 A 与 dV 的 A 共享同一 SMEM 区（一物两视图）：读读无冲突，
  生命期同 stationary（token 常驻），无新协议面。
