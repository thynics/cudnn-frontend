## 组合算术与执行序

M1+M5+M3 → math ~3.2-3.8；D1+D2+残差 → drain ~3.7-4.2；S1 结算 → **period ≈ 4.2-4.7，擦到平价带**；
M6 已死不再计入。
**裁决 A 已结（2026-08-03，B200 实测 benchmark/dsa/mma_atom_price.py，with-lock 通道零迭代跑通）**：
真实原子单价 = **max(发射地板 ~10ns, FLOPs/30TF·SM对)**——N16=10.1 / N32=11.2 / N64=13.4 /
N128=17.2 / N256=34.6 ns/atom(net)，N≥128 打满峰值 30 TFLOPS/SM对（CG2 原子税=1.00 三度确认）；
fixed≡rotate（描述符步进零成本，chase 白拿）。旧锚 0.03-0.045µs 作废（偏高 2-3×）。
后果：**T3-64 影子墙蒸发**（144 原子/64kv ≈ 1.9µs ≪ 4.3-6.5），band 收敛 ~5.0-5.6 安全侧，

MMA 在本图一切手术组合中不再定速（M1/M2 的 FFMA 压力走 CUDA 核，与张量管无争）。
执行序：探针周已结 5/7（D3 死、M2 数值门过、M6 死、裁决 A 绿、D2 备好待批次）；
