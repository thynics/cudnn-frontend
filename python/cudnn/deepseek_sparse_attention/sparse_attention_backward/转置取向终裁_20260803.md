# 终裁 —— 转置取向重构 (Sᵀ=K·Qᵀ, 头落 N 轴)

## 1) 裁决: **CONDITIONAL**

**一句话**: 取向本身成立且是首个在构造层面双消"供应墙+锚点边"的架构, 但 B200 原案 (T-128b-share/T1) 经双红队独立证明存在结构死锁, 予以击毙入律; 方案以 **Rubin-native T-128b-wide 为主设计、B200 仅存 T2 探针分支**条件放行, 全部前置门零 GPU, 不消耗 B200 rev。

## 2) 三红利两坑逐项裁定

| 项 | 裁定 | 要点 |
|---|---|---|
| **R1** P/dS 生而转置 | **半兑现 (弱形态)** | A-from-TMEM 指令级真实 (mma_sm100_umma.hpp:660, M∈{128,256}:637, a_major==K:639 在新取向下满足), 但 M=128 下 TmemAllocMode::Duplicated (traits:2176, :562-570) 与 C 折叠 DP 错位 → 跨 warp 8KB 弹跳 ≥ stmatrix 本体, **T-128a 枪毙**; T-256 (真 R1) 死于 B200 SMEM (驻留再×2) + 零松弛双别名, 仅 Rubin 另案。兑现部分: P 的 DSM/relay/count-512/pds 锚点边**整链退役**, 只留 16KB 本地发布——锚点边是结构性拆除而非搬家 (v18a 教训的正面解)。 |
| **R2** 软 max 跨 CTA 合法 | **全兑现** | backward softmax 纯逐元素 (LSE/Δ 为前向 per-(token,head) 常数), UMMA_2SM fold 使每 CTA TMEM 恰持 [own kv64×全 H128], 零跨 CTA 归约。代价有界: 列轴常数 warp-uniform LDS +0.03-0.15µs/bundle、stats 双份 1KB、Rep8/grouped-stats 宿主重推 (SASS 门); 尾块 mask 逐列→逐 lane 谓词反而变简。 |
| **R3** 副本环轴变 | **全兑现, 全案经济学核心** | 错配守恒但全部迁到 B 侧流式位: 供应字节 320→192KB/CTA/128kv (−40%), gens 20→12, K=H128 单趟走完免 H_PASSES=2 重演; 按 v13 圈固定成本定律, 供应墙 4.3-4.6 → **2.3-2.9, 首次退出定速竞争**——唯一合法击穿 +4.5µs 接力亏损族的构造。带宽降至 ~3.4-3.7TB/s, H-chunk 案 F4 死刑不适用。唯一退化: B slab 内段 256B→128B, TMA 请求×2 待实测。 |
| **K1** dQ 孤儿 | **前提坍塌 (伪坑)** | dQ 现状本就是转置形态: DQ_MMA_TILER=(256,128,64) (v17a:141,150-151 实核), 新取向逐格保形仅 K 64→128, epilogue/kdq 全原样。真代价仅 dSᵀ 的 B 需对端 kv 半幅: 8KB/bundle 交换 (取代今日 dK-B 的 2×4KB DSM, per-kv 减半)——唯一幸存的跨 CTA 数据面。K1-b 三重死、CG1 混用契约级 UB, 均枪毙。 |
| **K2** 双 tile 捆绑连锁 | **实坑, 且焦点被红队精确化为致命死锁** | 12 项连锁中 10 项机械可控; 真死点是 TMEM/SMEM 联动: **F1 死锁不变量**——T1 单 dKV 槽 × P/dS 单 slab 共用 × 合并 drain 构成环长 4 依赖环 (dS发布←dV(r1)←槽轮转←drain(r0)←dK(r0)←dS), 任意发射序无解, 双红队独立证明。原账"T1 或 T2 二选一"菜单作废: **T1 在单 slab 形态下不可购买**。四条出路仅 T2 (dQ f16 累加) 在 B200 自洽。 |

**口径勘误入律**: CG2 N 粒度 = SS %16 / TS %32 (任务书引的 %8 系 CG1 M∈{64,128} 专属, umma.hpp:88-90 vs :555/:638); 本设计 N∈{64,128,256} 全合法, 未来任何 N=8/24 头切想法在 CG2 下非法。

## 3) 存活形态全景

### 3.1 主设计: Rubin-native **T-128b-wide** (五 GEMM 全 SS, 零 TS/R2T 依赖)

**五 GEMM (per 128-kv bundle)**:

| # | GEMM | (M,N,K) | A 来源 | B 来源 | C (TMEM/CTA) |
|---|---|---|---|---|---|
| G1 | Sᵀ=K·Qᵀ | (kv128, H128, D512) | score gather own-kv64 整驻 65,536B (B200: chase 2/4) | stationary Q own-H64, K-major 视图**零拷贝** | Sᵀ 64 列 (h-chunk N=64×2, 32+32 乒乓) |
| G2 | dPᵀ=V·dOᵀ | 同 G1 | sV≡sK 别名 | stationary dO, 零拷贝 | dPᵀ 64 列 |
| G3 | dV=Pᵀ·dO | (kv128, D512, H128 单趟) | **P slab SMEM** [own-kv64×H128] f16, 16KB 本地 stmatrix, 零交换 | dO slab [H128×D64] L2 TMA 4×16KB | dKV 合并累加 128 列 (T1 单槽 D-round×2, 双 slab 下合法) |
| G4 | dK=dSᵀ·Q | 同 G3 | **dS slab** 独立 16KB (解 F1) | Q slab 4×16KB | 同槽合并 |
| G5 | dQᵀ=Kᵀ·dSᵀ | (256, 128, 128) — 与 v17a tiler 同一, 仅 K 翻倍 | kdq 流 4×16KB (逐格同今) | dq_b [kv128×own-H64] MN-major: own 半本地 + **8KB peer 交换** | dQᵀ 256 列跨 tile 持久, b244255 epilogue 原样 |

**账**: SMEM ≈248-264KB ≤ 328KB (余量健康); TMEM = 64+64+128+256 = **512 恰满** (T1 暴露 0.15-0.7 入账, 可选 T2 消 T1); dS 双像照 F4 改账 (发布 16KB + dq_b 本地 8KB + DSM 8KB = 32KB 存储, math +0.05-0.1)。协议: P 跨 CTA 链/own-half bulk/H_PASSES 重演/MATH_STORE 锚点边四族整删; 新增 h-chunk 握手、dKV 轮转门、列轴 stats 广播; 12 gens 解锁环深 {2,3,4,6,12}。

**period (per-64kv 等效)**: max(供应 2.3-2.9, math 4.4-4.9, drain 4.5-5.05) + 接缝 0.3-0.5 ≈ **4.9-5.7, 中心 ~5.2-5.3**。

### 3.2 B200 分支: 仅存 **T-128b-T2 探针形态**

单 slab 分相共用 + dKV 双槽 + dQ f16 累加 (TMEM 64+64+256+128=512; 双槽消 F1 环); SMEM 231,424/232,448。period ≈ **5.0-6.1, 中心 ~5.5** —— 与已放行的 v19-MAXFUSE (5.2-5.9, 中心 5.5) 重合, **无边际价值, 不消耗 B200 rev**, 仅在零 GPU 门全过且 v19 rev 失手时复议。

### 3.3 对照与战略定位

- vs v19: Rubin 形态中心略优 (~5.2 vs 5.5), 但 5.0-5.2 下探角点的原主张系于已死的 T1+单 slab 定价, **降级为"待 gate ⑤ 实测证明"**。
- vs 4.6: **两代均不可达** (math 4.4-4.9 + drain 4.35 双墙原封)。战略价值在于: 一旦正交的 math/drain 双墙手术成功, v19 系将撞回供应墙 4.3-4.6 地板, 而本取向供应墙 2.3-2.9——**本案是双墙手术红利唯一能全额兑现的底盘**, 应作为战略储备立项而非当期提速手段。

### 3.4 rev 分期 (零 GPU 优先, 顺序硬性)

- **rev0 (全宿主/haifa 零 GPU)**: ① dQ f16 链式累加离线数值仿真过 atol=rtol=5e-2 (FP8 死刑同族契约, B200 分支生死门) + DSL CG2 acc=f16 编译探针; ② Rubin TMEM/描述符/cluster 语义确认 + **Rubin-vs-Rubin 环模型对局** (对照复活条款解锁的 v19 深环 ~5.0, 净优势 <0.3 则主设计降级为档案); ③ token-major 折叠下 P/dS/dq_b 三像 stmatrix 的 get_smem_store_op 推导 + SASS 门 (v8 STS.U16 前科); ④ chase 2/4 K-外层序窗算 + 旋转调度盖 math 逐边建模 (B200 专属; Rubin 整驻免); 顺带 CG2+TS 编译探针关掉 T-128a 复活期权。
- **rev1 (首次耗 GPU, 仅 ①-④ 全过后)**: slab 相位门/T1 暴露/chunk 握手边沿探针定价; B slab 128B 内段 fill 实测。
- **rev2**: 主刀 (Rubin-native)。

## 4) 死因入律 (kill list 增补)

1. **T1 单 dKV 槽 × P/dS 单 slab × 合并 drain = 结构死锁** (环长 4 不变量, 双红队独立证明); 该三件任何再组合一律直接驳回。B200 T-128b-share 规格原文无合法排程, period 不存在。
2. **T-128a** (M=128 A-from-TMEM): Duplicated 布局 DP 错位, 弹跳 ≥ 发布本体; 半开悬案 (PTX A-layout 若证实只读半 DP 区可复活, 探针关闭)。
3. **T-256** (真 R1): B200 SMEM 无解 + 零松弛; Rubin 另案。
4. **pad×2**: 被捆绑严格占优 (per-kv 列成本恒等, 吞吐减半)。
5. **K1-b / CG1 混用**: a_major==K 违例 + 双重交换 / PTX 同 kernel 同 cta_group 禁令。
6. **口径**: CG2 N 自由度为 %16(SS)/%32(TS), 非 %8。

**与 v19/Rubin 的和解**: v19-MAXFUSE 放行状态不受影响 (本案 B200 落点与其重合, 不构成替代); Rubin 赛道上两案由 gate ② 对局裁决, 胜者携带主 rev; 无论立项走向, 本轮确证的三项资产**永久入档供任何取向复用**——R3 供应轴变 (−40% 字节/圈数的合法构造)、R2 列轴 softmax (零跨 CTA)、K1 坍塌 (dQ 本就是转置形态, v17a:150-151)。
