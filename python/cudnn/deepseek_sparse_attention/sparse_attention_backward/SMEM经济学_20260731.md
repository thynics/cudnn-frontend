# SMEM 经济学：baseline 与 2-CTA 的字节账终审

（与《定速环根因报告》《CG2终局设计》互为表里：那两份讲时间账，本篇讲字节账。）

## 1. 两边的 SMEM 全景（每 CTA，上限 227KB）

| 符号 | baseline | v12 | 说明 |
|---|---:|---:|---|
| Qᵀ / dOᵀ 常驻面板 | 64+64 | 64+64 | 相同；baseline 里兼任 dK/dV 的 A（转置视图，零副本） |
| K tile | 64（全幅） | 32（半幅） | CG2 唯一字节红利；baseline 的 K 兼任 dQ 操作数（双视图） |
| dot/qt/kdq 竖切副本流转槽 | **0** | **32** | v12 专属；footprint 32K、流量 160K/tile、寿命 ~1µs/块 |
| P 区 | 8 | 12 | v12 +中转/落地（跨 CTA 交换件） |
| dS 区 | 8 | 20 | v12 +块状第二布局副本 +死中转 4K |
| stats/mbar | 1.5 | 1.5 | |
| **合计（余量）** | **209.5（17.5）** | **225.5（1.5）** | 净差 +16K |

## 2. baseline 的字节效率：已近算法下限

baseline 的每一块字节都身兼多职：Q 面板 = S 的 A + dK 的 A；K tile = S/dP 的 B +
dQ 的操作数；dq_epi 别名进 K 区。其工作集 209.5KB ≈ 该算法在"H-own 所有权 ×
H-local 归约"设计点上的信息论最小值。**baseline 的 SMEM 利用本身已是极限形态，
不存在"再优化 baseline 字节"的空间**；其 17.5KB 余量是"不需要花"而非"没花好"。

## 3. v12 膨胀的因果证明（唯一根决策 → 四条推论）

根决策：把 dK/dV 的 H128 归约做成一条 cluster GEMM（消 atomic 税 + 发射减半）。

| 推论 | SMEM 项 | 为什么省不掉 |
|---|---|---|
| 收缩维=H128 ⇒ A 需 [D半×全128头] 竖切 | dot/qt 流转槽 +32K | 常驻需 +128K（353>227 死）；视图直读死于 CG2 共享描述符同地址规则；FP8 减半死于 f16/f8f6f4 ISA 互斥 |
| dQ 按 D 劈 ⇒ K 需第二种切法 | kdq（并入槽） | 同上布局锁 |
| B（P/dS）按头生产、按 token 消费 ⇒ 跨 CTA 交换 | P/dS 交换件 +16K | peer 半只存在于对方 SMEM（P/dS 无 GMEM 副本），DSM 推送为唯一通路 |
| 红利：K 由 CTA 对合持 | −32K | — |

**四把锁串联 = dot/qt 死刑**：布局锁（K-major↔MN-major）→ 描述符锁（两 CTA 同
地址）→ 字节锁（304>227）→ 协议锁（槽释放焊死在消费完成沿）。va1（全 CG1）
消融实验证明拆锁即愈（4.94µs），但违反 CG2 铁律，仅作校准点。

## 4. 生命周期谱系（问题的微观本体）

| 数据 | baseline | v12 |
|---|---|---|
| dK/dV 的 A（dOᵀ/Qᵀ） | **永生**（常驻视图，永远就绪） | **~1µs 单次副本**（填 0.7µs → 读一次 0.1µs → 即焚；tile 不变却每 tile 转世，全 kernel ~512 次复印） |
| dK/dV 的 B（P/dS） | 单 tile，一道门（math 算完） | 单 tile，三道门（math 发布 + token 重切 + 跨 CTA 落地） |

baseline 无任何 pass 级寿命数据；0.43µs 短命类是 v12 的发明，也是定速环的宿主。

## 5. 汇率结算（字节税 vs 时间税）

- baseline 用 **0.6µs/tile 的 GMEM atomic 时间税**买断全部字节复杂度；
- CG2 退掉 atomic、发射减半（合计赚 ~1.7µs），却付出**供应/交换税 ~4.5µs**
  （160KB/tile 复印流转 + 发布串联），净亏 ~2.4-2.8µs —— 与实测 4.71→6.5-7.1 吻合；
- v19（双缓冲三件套）可赎回其中 ~1.0µs（中心落点 5.5，≈9.7ms），供应环本体
  不可赎（字节+相位+协议三锁）。

## 6. 硬件代际复活条款

本死局对两个硬件参数线性敏感，满足任一即全盘翻案：
1. 每 SM SMEM ≥ ~288KB ⇒ dot/qt 就地常驻，供应环蒸发，CG2 纸面收益全额兑现；
2. tcgen05 放开 f16×f8f6f4 混型（或同 kernel 混 cta_group）⇒ 副本减半可驻 /
   梯度归位合法。
届时以 va1 的 4.94µs 为已验证下界重启。
