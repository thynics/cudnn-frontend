# T3 —— 细粒度全 f32 转置形态设计终稿（倒推法，B200）

**评审流程**：3 设计师（粒度档位独立）× 2 类对抗审计（账目/死锁）× 1 完备性批评，8 席全零 GPU。
**一句话结论**：唯一幸存点 **T3-64**（h_c=64, D_c=128, dKV 双槽, 全 f32），period 5.0–6.0 中心 ~5.5，
与 v19-MAXFUSE 同档但不穿透；带一处必修缺陷（dq_b 别名违例）与两颗前置裁决（原子单价 / chase 8KB）。
批评家标定唯一可能穿透 5.5 的空白点：**D_c=256 单槽相位拆分**（理论中心 ~5.3，待一页窗算裁决）。

## 0. 铁律（本案立法基础）

1. **精度铁律（2026-08-03 用户立法）**：相对 baseline 任何精度降低一票否决。全部累加器 f32、
   操作数 bf16、跨 tile 归并 f32 GMEM atomic（与 baseline 同类）。f16-dQ/T2 分支、FP8 战略线因此出局。
2. **CG2 铁律**：全 GEMM cta_group::2；whole-CG1 收益无意义。
3. 参照系：baseline 4.71 ｜ v17a 实测 6.5（最优 CG2 锚点）｜ v19-MAXFUSE（批准未建）5.2–5.9 中心 5.5。

## 1. 方法论：倒推法三元组

差距根因（定速环报告）= 生产切法≠消费切法 → 供应件皆为轴变换**副本** → 副本着陆区被消费者占有 →
释放门（禁止提前）→ 每件 0.4µs 协议租金 × 10 gen。v12 的 grad 已是空间细切（2+4+4），缺的是**时间
流水化资格**——依赖图是链不是叶。解法三元组，缺一不可：

| 要素 | 作用 | 缺失的墓碑 |
|---|---|---|
| ① 切分轴对齐（swapAB, Sᵀ=K·Qᵀ） | 定性：供应件从副本变纯输入，释放门整族拆除 | v13 同轴细切归零；H-chunk M-floor |
| ② 粒度（h_c, D_c） | 定量·空间：TMEM 槽缩小，全 f32 双槽 512 列闭合 | 旧 T2 粗粒恰满→单槽死锁→f16→撞铁律 |
| ③ 流水编排 | 定量·时间：两个覆盖不等式 + 无环 | F1 环长 4 死锁前科 |

倒推链（唯一解）：grad 理想消费形态 → P/dS 以 [kv×头] 生产 → 分数面同形定律 → Sᵀ=K·Qᵀ →
K/V 升 A（own-kv64 gather + chase）、Q/dO 降 B 之源（面板零拷贝 32+32 供片）→ B 三流 L2 直读自由抢跑。
边界：dQ 侧倒推提前终止（K1 坍塌，(256,128) tiler 与 b244255 epilogue 原样）；drain 侧顺推继承。

## 3. T3-64 方案主体

**TMEM（列/CTA，全 f32）**：dQᵀ 256（持久，2 D-round）+ S 乒乓 64 + dP 乒乓 64 + dV 槽 64 + dK 槽 64 = **512 恰满**。
**SMEM（B/CTA）**：K chase 2×8,192=16,384 + Q 面板 65,536 + dO 面板 65,536 + P slab 16,384 + dS slab 16,384
+ 供应环 2×16,384=32,768 + dq_b（修正后，见 §4）+ stats/mbar ≈ **231,424 / 232,448**（余 1,024）。
**排程**：dr-major（chunk 最内层）为唯一无死锁序；12 gens/bundle（mod 2=0 相位律 ✓）；
leader **钉桩**：在 G3(c1,0)(t) 的 P1 等待点先行发射 ①(t+1) chase 原子（否则 math 窗遮蔽主张落空——审计修补①）。
**墙位**：供应 2.3–2.9（已拆）；math 4.85–5.8；drain 4.7–5.45（+8 趟税 0.2–0.4）→ 定速 = drain/math，
MMA 影子墙 4.3–6.5（原子单价 0.03–0.045 锚宽所致，见 §6 裁决 A）。

## 4. 必修缺陷（批评家发现，两轮审计漏检——T3-64"双审通过"状态作废）

G5 排程原文"own 半 B=dS slab 别名 + 两描述符"**违反 CG2 共享描述符同地址规则**（与细档被推翻的错误同构；
kill-list "own-half 零拷贝死刑"原案重现）：任一 kv64-half 原子中两 CTA 读不同基址区，非法。
**修复 = dS 双像**：dq_b own 半改为独立本地像 [kv128×own-N-half] 8,192B（own 半 stmatrix 二次落地，
math 税 +0.05–0.1/bundle）；同时纠正 DSM 字节双算（N-劈下 peer 半只需 8,192B，省出的恰好补上本地像）——
**字节近中性，但 SMEM 账⑦语义、G5 发射方式、死锁图 dq_b 边族需重写并过第三审。**

## 5. Kill-list 增补（本轮入律）

1. **N16 发射税定律**：分数面原子数 ∝ 1/h_c 且窄 N 原子按全价计费（现行锚）→ h_c=16 档 MMA 忙线自成
   定速墙（~13µs）。翻案唯一扳机 = 硅上证明窄 N 按 FLOPs 比例计费。
2. **dq_b/own-half 别名死刑重申**：CG2 同地址规则下"slab 别名 + 落地区拼 B"不可构建，双描述符解不了秩不对称。
3. **chase 释放边入图义务**：任何把 "piece 就位"当外生事件的死锁证明不完整；V≡K 单取数强制 K-外层序。
4. **流程律**：自判死方案必须过至少一轮审计（中档假阴性无人拦截的教训）；建共享引理表
   （chase 释放边 / 同地址违例实例 / dq_b N-half 尺寸 / 簇级到达门 / drain warp 内序），每案强制过表。

## 6. 两颗前置裁决（先于一切 rev0，任一不利即改判）

- **裁决 A：MMA 原子单价 microbench**（B200 小探针：v17a 管占用率读数 + N16/N64/N128 背靠背）。
  ≤0.035 → T3-64 band 收敛 5.0–5.6 安全侧（细档同时终审）；≥0.045 → MMA 管墙 6.5 接管，T3 连 v17a 都不赢，全案归档。
- **裁决 B：chase 8KB（D_c_k=64）**。本案裁定：**规格层面放行**——gather 行段 128B 与 dS-B 슬랩"256→128B
  请求×2 待实测"同族，swizzle/相位审计合法；风险定价为 rev1 fill-rate 探针。若实测 fill 恶化 ≥2× 则 T3-64
  无退路（审计已证退路包缺 2,048B）→ 全案死。

## 7. 待裁变体：D_c=256 单槽相位拆分（唯一可能穿透 5.5 的点）

dQ 256 + S/dP 乒乓 128 + 单共享槽 [kv64×256]=128 → 512 恰满；drain 趟 8→4（−0.1~−0.2 直击定速墙），
理论中心 ~5.3。毒点：单槽使本槽 drain 无法被累加遮蔽（T1 族暴露回归），净收益可能归零。
**行动：一页窗算正式裁决；净赢 ≥0.2 则升格为 rev0 主形态。** 另：dV/dK 异粒度（dS 双消费的结构性
不对称缓冲）边际 −0.05~−0.1，列举备查；G3/G4 可按 32 头半块尾随发布逐半启动（零原子成本接缝削减，
排程期权）。

## 8. 战略定位与期权账

- **当期换代走 v19-MAXFUSE**（中心同 5.5，已批准、方差小、零三审欠账）。
- **T3-64 = 战略储备底盘**，晋升扳机（三与门）：原子单价 ≤0.035 ∧ chase fill 实测过 ∧ math/drain 双墙
  手术立项。届时 v19 系撞回 4.3–4.6 供应地板，T3 是唯一全额兑现手术红利的底盘（终裁原判维持）。
- 期权登记：排程微调余量 0.2–0.4（leader 回填/drain 交错/逐半启动）；Q/dO 双取 ~128KB/bundle L2 流量
  （今日供应不定速故零收益，双墙手术后的下一根杠杆）；kdq≡K 别名（chase 槽短寿命所杀，硬件代际复活条款）。
- Rubin：SMEM/TMEM 松绑 → 恰满账变宽裕账，直通 T-128b-wide（另案）。

## 9. rev 分期

- **rev-gate 0（先裁后动）**：裁决 A（B200 小探针）+ D_c=256 变体窗算（零 GPU）。
- **rev0（零 GPU）**：dS 双像修复 → 死锁图补边（chase 释放边/簇级聚合门/钉桩排程/drain warp 序）→ **第三审** →
  stmatrix 三像 get_smem_store_op 推导 + SASS 门（v8 前科；v17a 参照物已存档 scratchpad）。
- **rev1（首耗 GPU）**：chase 128B 段 fill-rate 探针；槽相位/接缝边沿定价。
- **rev2**：主刀实现（`dsa_bwd_sm100_2cta_t3.py`，harness 类名合同照旧）。
