# final_ser 设计文档（2026-08-11，rev2：去借用版）

> 目标：以 `dsa_bwd_sm100_2cta_final.py`（v_w3_2 血统，B200 9.44ms/1.137×）为基座，
> 实现"图二/理想图"流水线的 2-CTA 版本：**同 tile 串行五 GEMM 链 + 高度 overlap**。
> 编号 `final_ser`，文件 `dsa_bwd_sm100_2cta_final_ser.py`，类名保持
> `FlashAttentionDSABackwardSm100TwoCTAV2`（sweep harness `--impl final_ser` 默认类名直接可用）。
>
> rev2（用户 2026-08-11 理想图确认）：**不做 score_kv 复用（dO 借用）**——dO_r0
> 走普通 ring 代，score_kv 每 tile 只装一代 K；借用留作后续优化。

## 0. 定位与诚实预期

final 的旋转调度（S/dP(t) 先发、grads(t-1) 藏其影下）是对"同 tile 串行暴露
softmax 链 ~0.5-0.6µs/tile"（优化设计文档_v2.md:187-208 评审）的规避。final_ser
是该变量的**受控反演**：把发射序改回同 tile 串行，同时把 overlap 工程做满。

台账先例（本设计逐条绕开其死因）：
- v0 纯串行 23.4ms / V1A0 ~10×：死因是 3×48KB 通用 FIFO / 450KB 片上重写，
  不是串行序本身。final_ser 沿用 final 的数据面（驻留/ring/交换/drain/epilogue）。
- v_final_exgh P-early +0.21ms：死因 = 旋转序里 dQ 在梯度块首位等 dS，P 先发
  反而推迟 dS。final_ser 中 dQ 在链尾，dS 有整个 dV 窗口作掩护，依赖方向相反；
  拆 fused 循环的 ILP 税仍在（~0.6µs math），但 math 在串行序里有 dV 窗冗余。
- E1/v_s1 分块流式崩溃：不新增流式通道；KV tile 维持整块 gather（gather 不在
  关键路径，E5b）。
- 预期落点：暴露项 ≈ P 链（S 完→P 发布→DSM 落地→dV）未被 dP 盖住的部分
  + KdQ gather 尾巴（~0.4µs），模型预测 ~5.8-6.3µs/tile ≈ 10.3-11.2ms @2048，
  慢于 final 9.44。价值：(a) 终审"五次单腿手术 standalone≈0"暗示存在 ring 模型
  外的共同定速项，本实验整体更换依赖结构，是信息量最大的单次实验;
  (b) GR100 上 82% stall 是同步自旋，串行链大幅简化同步结构。

## 1. 理想图 → 代码的逐块映射

| 理想图元素 | final_ser 实现 |
|---|---|
| Load Q / Load dO（序幕） | 不变：W17 stationary TMA，Q/dO 分离就绪（S 只等 Q，dP 只等 dO） |
| Gather KV（tile 头） | `_load_score_kv` 整块 gather K(t) 进 score_kv（K=V，一次 gather 喂 S 和 dP；不分块流式）。**无借用：score_kv 每 tile 一代 K**，K(t+1) 在 dP(t) 释放后立即 gather，被 dV/dK/dQ 全窗盖住 |
| S=QK → dP=VdO | 不变：`_issue_score_v2` ×2，CG2，TMEM ping-pong |
| dO0..dO3 / Q0..Q3 | round ring 8 代 TMA fill（own 半 bulk s2cluster + peer 半 TMA，L2 热），**顺序 = 消费序**：dO_r0 对 → dO_r1 对 → Q_r0 对 → Q_r1 对 |
| K0-K3 再载（dQ 前） | = KdQ 融合双轮 gather（`_gather_kdq_v8`），**ring 尾部 g8/g9**（共 10 代/tile，10%2=0 相位铁律保持），dK 窗口作掩护，dQ(t) 同 tile 消费 |
| P → exhg | math **P 相**：T2R S → exp2 → stmatrix P blocks/xchg → fence → `p_ready_mbar`(新, count-128) → W18 立即 DSM 发 P → 落地 → relay0（语义与 final 一致，只是提前到 dP 影子下） |
| dS → exhg | math **dS 相**：T2R dP → dS → stmatrix ds blocks + ds_image → fence → `pds_ready_mbars`(沿用) → W18 发 dS → pds commit → 落地 → relay1 |
| dV | dV r0（ring dO_r0 × p_blocks，门：relay0）→ dV r1（ring dO_r1 × p_blocks），slot0/slot1 各 ACC=False 初始化 |
| dK | dK r0（ring Q_r0 × ds_blocks，门：relay1）→ slot0 commit → dK r1（ring Q_r1 × ds_blocks）→ slot1 commit（dV+dK 融合同一 TMEM 槽，K=V） |
| dQ | `_issue_dq_rounds_v2` 双轮（ring KdQ0/1 × 本地 ds_image），TMEM 跨 tile 累积；dq_done commit 在循环后（串行序里 dQ 本就是末 GEMM，时机与 v12 early-commit 等价） |
| reduce | 不变：`_drain_dkv_v8`，slot0 在 dK r1+dQ 窗 drain，slot1 滑进下一 tile 的 S/dP 窗 |

## 2. 每 tile 稳态时序（leader 视角，无旋转）

```text
kscore.wait(K(t)) → S(t) → dP(t) → kscore.release
      [gather: 观察释放 → gather K(t+1) → commit（dV/dK/dQ 全窗作掩护）]
      [math:   S done → P 相 → p_ready；dP done → dS 相 → ds_ready]
      [W18:    p_ready → 发 P → P 落地 → relay0；ds_ready → 发 dS → pds commit → dS 落地 → relay1]
relay0.wait → dkv_done.acq(slot0) → ring×2(dO_r0) → dV r0 ×2
dkv_done.acq(slot1) → ring×2(dO_r1) → dV r1 ×2
relay1.wait → ring×2(Q_r0) → dK r0 ×2 → dkv_done.commit(slot0)
ring×2(Q_r1) → dK r1 ×2 → dkv_done.commit(slot1)
      [gather+W17: ring g8/g9 信用 → kdq_barrier 会合 → KdQ(t) 融合双轮填 → kdq_ready]
ring×2(KdQ) → dQ r0/r1（ACC=跨tile）→ pds.release；[循环后: dq_done.commit + tails]
```

关键掩护账（µs，B200 口径）：
- dO_r0 环填（~0.3×2）在 dQ(t-1) 释放 g8/g9 后立即开始 ⊂ S(t)+P math 窗 ✓
- dS math+发（~1.6-2.0）⊂ dV r0+r1 执行窗 + dK r0 等待自然后移，微暴露
- K(t+1) gather（~1.3）⊂ dP(t) 释放后的 dV+dK+dQ 全窗（~3.5）✓（比借用方案更早）
- KdQ(t) gather（~0.4-0.5）尾部暴露 ≈ 0.4/tile —— 已知税，见 §0
- ring 供给：10 代/tile × ~0.3µs 填时，W17 恒领先 2 代，总供给 ~3µs < 周期 ✓
- reduce：slot0 commit 后有 dK r1+dQ+下一 S/dP ≈ 3µs 窗 > drain 2.5 ✓

## 3. 同步结构 diff（相对 final，最小手术原则）

新增：
- `p_ready_mbars` Int64[1]（count=MATH_THREADS=128，+8B SMEM，slack 1536B 内）

语义改变（结构不变）：
- `pds_ready_mbars`：从"P+dS 全部发布"变为"dS 相发布"（ds_ready）
- W18 relay 拆两腿：P 腿（等 p_ready → 发 P → 等自身落地 → arrive relay0）、
  dS 腿（等 pds_ready → 发 dS → pds commit → 等落地 → arrive relay1）；
  relay_mbars/landing_mbars/pds commit 位置全部照旧
- pipe_round 代序：`dO0,dO1,dO2,dO3,Q0,Q1,Q2,Q3,KdQ0,KdQ1`（10 代 % 2 stages == 0）；
  W17 g0..g7 TMA、g8/g9 会合提交；W19 转发 g0..g7、跳 g8/g9
- pipe_kscore：每 tile 一代 K（原 K+loan 两代）；gather 每 tile 程序序 =
  K(t+1)（若非末 tile）→ KdQ(t) 会合；tile_count==1 特判与 noop-recommit 删除
- leader：删除旋转（prev_grads head/tail + 循环外末 tile drain）；
  新 `_issue_grads_ser_v1`（全 ring 消费）；dkv_done 拆 acquire/commit 双
  producer state（镜像 reduce 侧 split wait/release 先例）；dq_acc = loop_iter != 0；
  dq_done commit 移到循环后
- math：fused 单循环拆 P 相 / dS 相两段（grouped-stats 索引两相共用）

完全不变：host `__call__`、SharedStorageV2 布局（仅 +1 mbar 字段；loan 字段保留
未用，供后续复用优化）、TMEM 图、DKV/DQ MMA tiler 与 pass 结构、drain、
dQ TMA epilogue（loan_epi_safe 协议照抄，现锚定末代 K 的 producer_tail）、
convert_canonical、sum_OdO/sum_dSink、reverse tile 序、零 tile 退化路径、
kdq count-128 硬件到达协议（R2）、OWN_HALF_BULK、stmatrix 发布布局与字节恒等断言。

## 4. 已知风险与对应门

| 风险 | 门/缓解 |
|---|---|
| math 拆相 ILP 税 ~0.6µs（exgh 实测） | 串行序下 math 冗余度 = dV 窗口；若 trace 显示 ds_ready 迟于 dK r0 需求点，回退：dS 相先算后存 |
| KdQ 尾部暴露 | 已计入预期；后续旋钮：KdQ(t+1) 提前一拍（9 代方案）或恢复 score_kv 复用装 KdQ |
| dO_r0 进 ring 使供给 +2 代 | 填时 ~0.6µs 增量,在 S+P 窗内;若 W17 供给成为 pacer,后续恢复借用（rubin_1 逆操作） |
| slot0 commit 后移拉长 reduce 首启 | slot0 drain 窗仍 ≈ 3µs > 2.5 ✓ |
| 相位记账（kdq_phase/relay_phase/landing_phase 随代序变化） | 对抗审查 workflow 逐相位复核 + trace 版本插桩位映射 |
| PTXAS 寄存器（leader 串行块） | 叶子复用不展开新循环；沿用 unroll=4 教训 |

## 6. 实测判决与事后分析（2026-08-11，B300 SXM6 AC / cc 10.3）

- 正确性：四门全过；对 baseline 交叉核对 **dQ 位级零差**、dKV 差一个累加序 ulp（0.000488）。
- 性能（fair_direct_program_only，24 对 ABBA）：baseline 7.630ms，**final_ser 11.114ms
  （494.7 TFLOPS），1.4565×（−45.65%）**。
- 对抗审查复核（9 agent）：记账/死锁/数值/DSL 四维度零 HIGH；
  确认两项模型缺陷——(1) §1/§2 的"P 交换藏进 dP 影子"声明定量为假：dP 影子仅
  ~0.35µs，P 发布链（T2R S 0.6-0.8 + 拆相 exp2/downcast 1.0-1.4 + stmatrix 0.3-0.4
  + count-128 尾 ≤0.448 + W18 腿 0.3-0.45）≈ 2.6-3.6µs，**relay0 前的 TC 气泡
  ≈ 2.2-3.2µs/tile，是串行形态的主导结构项**；(2) §0 预测带 5.8-6.3µs/tile 由此
  不可达。静态复核模型（中位 8.6µs/tile）反向偏悲观；实测 ≈ 6.3-6.8µs/tile
  介于两者之间——最终逐项定价需 span 实测（见 trace 协议）。
- B300 放大效应：baseline 从 B200 8.62 → 7.63（算力缩短 GEMM），而暴露项是
  延迟型（math 链/DSM/集合 arrive/gather），不随算力缩放 → 串行税的相对占比
  随硬件代际上升（Rubin 上会更差）。旋转的必要性在新硬件上更强，不是更弱。

## 7. IKET A/B span 分解（2026-08-11，B300，稳态 tile 10-24）

周期：baseline 4.45-4.50µs/tile vs final_ser ~8.0µs/tile（IKET-on 口径，方向与 release +45.65% 一致）。
结构验证：单 tile 五 GEMM 串行链与设计一致；K(t+1) 预取提前 ✓、dS math 藏进 dV 窗 ✓、
reduce 原子体反而更快（0.934 vs 1.503，rank 劈半兑现）✓、S/dP 发射更快（0.44/0.50 vs 0.55/0.59，CG2 兑现）✓。

| 1 | dP 末 → 首 dV（relay0 门） | **1.77**（其中 P relay wait 1.43） | 2.2-3.2 | P math 本身仅 0.34（≈baseline 0.31）——**链的大头是发布+集合+DSM+落地（P publish 0.50 vs baseline 0.066），不是 math** |

| 3 | 末 dK → 首 dQ（KdQ 尾） | **1.27**（RING_WAIT 包络 1.72） | 0.4 | 低估 3 倍：会合链（信用→barrier→gather→count-128→commit）整体计入 |

杠杆重排序（按实测收益）：
1. **借用回收（loan 复用装 dO_r0，ring 10→8 代）**：同时打 #2 和 #3（KdQ 会合提前一拍），预计 −1.2~−1.8；
2. **count-64 子门 + 发布链重构**：打 #1 的 0.5-0.9（DSM+落地 ~0.4-0.6 是结构地板）；

### §8 附:第一轮变体判决(B300, alloc 3592663)
- **final_ser_k1 = 零收益**(11.177ms,比 ser 腿 ±0.21% 噪声;正确性四门+crosscheck 全过)。
  **cluster 编码假说被硅上证伪**——P_PUBLISH 0.48µs 的膨胀不是 arrive 编码,残余嫌疑人:
  (a) spill(math 也在 272B 栈帧热点里),(b) 线程参差(无前置 barrier 对齐),

- **final_ser_kq 编译失败已修**:kdq_loan 裸 recast_ptr 丢失对齐推断(2B),cp.async 128-bit

  score_kv 基址 1024 对齐,+16KiB 半区偏移保持)。

而 baseline 的同类操作既少又是 CTA 域**。跨代不变性(B200/B300 各 span ±10%)与
"指令相同耗时数倍"皆由此闭合。
可证伪预测(NCU PC 采样,在途):stall 应集中于 MBAR/FENCE 类指令而非 STSM/LDSM;
若 stall 主要落在 STSM 上则本假设作废。
潜在优化线索(未验证):pipe_round 等若可降为 CTA 域(producer/consumer 同 CTA 时),
每 tile 可省 ~0.5-0.9µs;但 CG2 B 操作数 N-split 可能要求 cluster 可见性,需逐管线审。

(a)回 1-CTA 框架做增量优化(packed math / K1a 寄存器 / 出链三刀可直接移植);
(b)重新划分 2-CTA 的切分维度,使 P/dS 不跨 CTA(代价是 dKV 侧聚合,需重新算交换账);

### §10.4 补:kq6g 具体几何(drain 映射解码,20260812)
_drain_dkv_v8 映射:256 线程/CTA = 2WG×128;dp_idx//4 = 128 列子瓦内的 16B 槽
(32 槽),dp_idx%4 = chunk 四元组内行选择;每 WG 每 chunk 盖 4 个 KV 行 × 128 列,

子瓦分派:slot0 列 [rank*128,+128),slot1 列 [256+rank*128,+128)。
REDG 账:16/线程/tile × 256 = 4096 REDG.F32x4/CTA/tile。
kq6g 方案:行内 32 线程 STS 至 512B staging(地址互斥无冲突,STS 不出 SM)→
WG 同步 → elected thread 发 cp.reduce.async.bulk.global.shared::cta.bulk_group.add.f32
