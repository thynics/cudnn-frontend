# 2-CTA DSA Backward 终审报告

**结论先行**：2-CTA 在 H128/D512/S4096/topk2048 上定格 **~11.62ms vs baseline ~8.04-8.28（1.41-1.44×）**，
判定无法超越 baseline。计算本身无罪（CG2 原子税 = 1.00，张量核占空仅 21.6%），
输在一个机制家族：**梯度操作数不常驻 → 每 pass 走一圈信用环接力**。

---

## 1. 方案：在 baseline 之上做了什么

baseline：1 CTA 拥有 64 头，Q/dO 常驻 SMEM，K 每 64 头加载一次，partial dKV 经
GMEM atomic 合并（每 tile 付 ~0.60µs atomic/reduce 耦合）。

2-CTA（最终形态 = v12 血统，`dsa_bwd_sm100_2cta_final.py`）：两个 CTA 结成
cluster 共有 128 头，所有 GEMM 用 CG2 原子（M 维劈到 SM 对）：

周期对账（同口径 pacer 账，µs / 128h×64k tile；合计即两条 critical path 总长，
两套独立采集闭合 ±0.02）：

| 周期分项 | baseline | 2-CTA | Δ | 归因 |
|---|---:|---:|---:|---|
| S/dP 发射 | 1.27 | 0.96 | −0.31 | CG2 原子数减半 |
| dVdK 发射 | 1.12 | 0.46 | −0.66 | CG2 原子数减半 |
| K 供应等待 | 0.13 | 0 | −0.13 | K 跨 128 头复用 |
| reduce/atomic 耦合 | 0.60 | 0 | −0.60 | dKV 片上收缩 |
| 供应接力等待 | 0 | 3.03 | +3.03 | 操作数流式化，2 槽信用环每 pass 一圈 |
| 接力环头部间隙 | 0 | 0.77 | +0.77 | 同上 |
| 接力环尾波 | 0 | 0.68 | +0.68 | 同上 |
| 其余（未单列公共段，由合计反推） | 1.59 | 1.22 | −0.37 | — |
| **period 合计** | **4.71** | **7.12** | **+2.41** | |

流式化的根因：D 维劈半使收缩维覆盖全部 128 头，Qᵀ/dOᵀ 驻留需求 256KB
超出 227KB SMEM 上限，退化为每 tile 流式 128KB。

## 2. 流水线排布

20 warps/CTA 特化：gather×4（K(t+1) 预取 + kdq 填充）、math×4（softmax→stmatrix
发布 P/dS）、reduce×8（dKV T2R+atomic，环外）、W16 leader（唯一 MMA 发射者）、
W17 supply（round 环 10 gen/tile：2 kdq + 8 quadrant panel，深度 2）、W18 relay
（P/dS 跨 CTA DSM 路由）。

Leader 主循环（v7 关键重排）：**S/dP(t) 在 grads(t-1) 之前发射** → math(t) 与上一
梯度块全程重叠，S/dP(t+1) 执行顺带盖住 publish 窗口。每 tile 梯度块：等 pds →
dQ×2 → dVdK×8（每 pass：等 fill commit → 4 原子 → 完成驱动释放）→ dkv 2 次
commit 交 reducer。

环结构（实测共同定速）：pds 一步环（math→W18→leader→完成释放）+ **W17 供应
接力环（每 pass 一圈：释放→W17 解锁→发射→TMA 飞行→commit→leader 走）**。

## 3. 收益被什么卡住了

**量化因果链（双数据源确认）**：

```
SMEM 字节墙（227KB，双份 panel 需 304KB）
  → round 环只有 2 槽（32KB ÷ 16KB/gen）
  → 补给无法提前（需 往返0.4 ÷ 节拍0.1 ≈ 4-5 槽）
  → 每 pass 裸等一圈 ≈0.38 × 8 圈 = 3.03µs/tile   ← 全部净差距的 126%
```

证据：24/24 pass 由 fill commit 扳机触发（发射距 commit 中位 64ns）；逐 pass
leader 余量仅 0.03-0.06µs——没有任何一段"慢代码"，慢的是**圈时/节拍比 + 禁止提前**。

单圈五段解剖（run2 探针边沿；链长经双方独立复算闭合，
dVdK_ISSUE 间距中位 0.464 ≈ 五段和 0.50，µs/圈）：

| 段 | 实测 | 身份 | 可压性 |
|---|---:|---|---|
| A | 0.19 | 前一 GEMM 真实执行完 + 完成信号跨 SM 组播 | 仅能靠减圈数摊薄 |
| B | ≈0 | W17 唤醒 | 已免费（"减唤醒"杠杆划掉）|
| C | 0.08 | W17 软件 | 边际 |
| D | 0.14 | 搬运露头（own bulk 0.11 / peer TMA 0.17，飞行窗仅 0.27）| 深度+1 可消 |
| E | 0.09 | commit + leader 唤醒（独立复核 0.064-0.092 一致）| 边际 |

**修复尝试与判决**（每项均硬件级证据）：

| 杠杆 | 判决 |
|---|---|
| 供应重排/配对（tmapair） | ❌ −2.49%（排列不变性） |
| 半粒度深度 4（v13） | ❌ 8KB 往返仍 0.35-0.4，槽位比恶化 |
| S/dP 再前置（v14a） | ❌ v7 已做到近极限 |
| L2-staged 交换（v15，已实测） | ⭕ standalone ≈0（接力补位吃掉）；定位为合成使能项 |
| own-half 零拷贝 | ❌ CG2 共享描述符禁 rank 不对称基址（硬件封死） |
| dVdK 并趟 8→4 | ❌ 评审击毙：深度 2 下配对占满两槽即 lockstep；A=exec+组播（0.163 近常数），exec 不随并趟摊薄——真实收益 ≈0±0.2；管线化形态需 +32KB 无来源 |
| round 深度+1 | ❌ 双重阻塞：需 +16,384B vs 全仓审计合法来源上限 5,632B（缺 10,752B）；10 gen/tile mod 3≠0 与静态 gen→buf 绑定相位不相容。唯一真实杠杆（−1.10~−1.81）但不可实施 |
| W19 急切提交引擎 | ⭕ 唯一幸存可执行项：拆延迟提交格（k_eff 1→2），−0.4~0.5µs、零字节；原"W17 双 lane"形态非法（cute.copy 隐式 elect_one，DSL 源码直证），改道空闲 W19 |

**终审判词（两把刀评审后加固，详见《两把刀评审_20260730》）**：追平需
period ≤4.6µs。五维评审 + 对抗复核（verdict 全部存活）：≤+16KB 预算内任何
（环深, 粒度）组合下界 ~5.2-5.3；头部 0.77 + 尾波 0.68（占追平缺口 58%）与
环深/圈数正交，两刀零触及；极端角点 4.6-4.8 三前提逐一被拒。**窄门关死，
架构级结论成立**。剩余可收项仅 W19 引擎，全兑现后 period ~6.6-6.7
（≈10.8-10.9ms）。
差距的根源（H-split 所有权 × D-split 计算的错位导致操作数不常驻）在此 SMEM
容量与 CG2 描述符规则下不可修复——**这是架构级结论，不是工程未尽**。
