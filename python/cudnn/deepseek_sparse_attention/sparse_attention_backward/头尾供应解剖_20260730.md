## 1. 三块猎物的实证结论

**头部 +0.77 —— 证实存在, 但可采额只有 ~0.2-0.3, 不是 0.77。**
leader 头部空洞 G = dP_ISSUE(t+1).end → WAIT_dQ(t,r0).start = 1.088/1.216/1.152 µs 稳态 (冷 tile1 1.728, i14_i17/i1_i3 CSV)。身份确认: 无 span 的 pds consumer_wait (final.py:2717), 其 full 由两 CTA W18 在双 DSM push 发射之后才 producer_commit (final.py:2599-2600)。四段分解逐 tile 精确守恒: math store 尾 0.256-0.448 + W18 唤醒 0.288-0.544 + 双 push 窗 0.320-0.576 + leader 唤醒 0.032-0.064。ACQ(q=0) 阻塞 0.800-1.216 (10/10) 的真门是本 tile kdq_a 槽释放 (= dQ r0 UMMA 读完成 +0.163, 两 CTA 同值); 结构根因是 2 槽环中 kdq 对占位 #0/#1, 锁死 2.56-3.04 µs 预填窗 (final.py:2404-2417)。三项排除硬证: ROUTE_K 移走提前量 = 0 (对 gen0 真门余量 0.832-1.248, 10/10); 前 tile 环槽在真门前 ~2.4 µs 已释放; relay landing 从不暴露 (7/7 由 gen0 commit 扳机, 0.032-0.160)。可采上限被双帽封死: kdq/ring 腿对 dQ 仅 0.3-0.6 余量 + math softmax 就绪帽 0.896-1.312 —— 头部手术全族 (P1+P2+P3 各形态) 合计实兑 ≤0.3-0.6, 其中唯一过验证的是 PDS_HOIST 的 0.19-0.29 (逐界直测)。

**尾波 +0.68 —— 大部证伪: ~0.55 是记账假象, 真残值 ~0.1-0.2 且无独立兑现路径。**
账面 0.68 (v12 trace, compare_pacer.py:100, 15/15 tile mean 0.685) 的同一物理段在 run2 探针版恒为 0.128 (3/3, S_ISSUE(t+2) 103.936 先于 g9 104.000 发射) —— 差额 ~0.55 是 v12 31-名 trace 构建的 leader 路径膨胀 + 记账迁移 (period 守恒: 迁入 pds park 0.44→1.25-1.28)。真尾波硬件事件全部不在缝上: exec drain 0.192 被 S/dP(t+2) 发射 0.90-0.99 完全覆盖; commit drain 0.096-0.256 只被 reducer 唤醒消费; reducer 对 leader 的 dkv_done 松弛 3.68-4.80 µs → dkv commit 粒度价值恰为 0 (且语义不可能: 每槽是 4-pass 满块 [D256×N64] 合并累加器, final.py:2739-2783/936-937, commit 已在最早合法位置)。MAT_WAIT(q7) 0.256-0.608 的尾波暴露已整体记入 W19 EAGER 的 −0.4~0.5 账内。尾侧独立杠杆经 P4 判决归零: loop-turn 前置按 diff 位置落地是 +1.0~1.5 回归 (kscore wait 上提阻塞 dQ), 安全位置收益迁入 pds park 归零。

**W17 供应复用 —— 墙占用 ~100% 是假象, 56.3% 是等待; 一切卸载周期收益 ≈0。**
稳态预算 (i14-17, 8 实例, period 6.88): ROUTE_K 包络 1.616 + gap 0.028 + MAT_QDO 包络 5.084 + 尾闲 0.197; 其中等待 3.87 µs (RK_ACQ 0.156 + MAT_ACQ 2.600 + MAT_WAIT 1.116), 真实工作仅 2.83 (41%)。"ROUTE_K 后空转 ~2µs" 证伪: gap ≤0.06 (14/14), 表观空转是 MAT_ACQ(q0) 的 span 内阻塞。kdq 腿对 dQ 稳态松弛 0.768-0.800 (i14/15/16 精确), 起点由 leader g6/g7 释放门定 —— 因此: 选项① ROUTE_K→W18 NO-GO (收益 ≈0 且慢 tile ROUTE_K max 4.384 会把绑定的 relay 腿拖后 ~2.7); ①b→gather 自管仅 +0.03-0.06, 只配零记账 rider; 选项② 腿拆分 PARK (与 EAGER 同打 k_eff→2, 增量 0-0.2 未验证)。W17 是 leader 信用的镜像; W18 忙 0.128-0.480/tile (~3.3%), 其空闲唯一能变现的就是 pds commit 位点手术。另勘误: 寄存器几何实为 W16-19@48 / math@128 / reduce@128 (final.py:1794-1800, 池精确 61,440), 非任务书的 64/120 —— G2 预检按更紧的 48 评估。

## 2. 方案包判决

### 幸存 (唯一)

**S1 · DSA_V16_PDS_HOIST (双评审独立 ALIVE_MODIFIED)**
- 机制一句话: 把 `pipe_pds.producer_commit` 从两条 DSM push 之后 (final.py:2599-2600) 上提到 pds_ready 等待之后 (:2556), 将慢 CTA 的 push 发射窗移出 leader 的 dQ 门。
- 修正收益: **−0.19~−0.29 µs/tile 稳态** (逐界直测 0.192/0.256/0.288, i17 界 0.54; 硬帽 ~0.3 —— 残余绑定 = 跨 CTA pds_ready 偏斜 + W18 唤醒 0.288-0.544, 不被本刀触及)。提案原报 0.4-0.5 被 CSV 证伪 (混 CTA 包络多算了唤醒偏斜 0.1-0.16)。
- 正确性: 无伤 —— dQ 的 B 操作数 = ds_image (final.py:1598), WAR 保护走 push源读→landing→relay_mbars(:2601-2616)→leader relay 门(:2735/:2758)→UMMA-deferred release(:2343)→math acquire(:2071) 结构链, 与 commit 位置正交; 但 :2717 后 leader 读位点重审清单须按此链重写。
- 件量: 3 行搬移 + 旗标化 ~8-10 行, 零 SMEM 零新 mbar。standalone 即全额兑现 (ring 腿在新沿处余量 0.22-0.32), 不需要任何捆绑。
- 验收/回滚门: WAIT_dQ.start − max_CTA(ROUTE_P.start 等价探针) ≤0.1 且 period 净降 ≥0.15; 否则确认 M1/L2X "另一腿补位" 判词, 回滚。
